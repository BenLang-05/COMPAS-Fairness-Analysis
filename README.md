# COMPAS Fairness Analysis

A data analysis project exploring the COMPAS recidivism dataset using Python and Jupyter Notebook.
The project evaluates predictive performance across demographic groups and investigates fairness through the use of confusion matrices and performance metrics.

## Features
Dataset exploration and inspection,
Descriptive analysis of demographic and offence-related variables,
Distribution analysis using visualisations,
Comparison of outcomes across race and gender,
Confusion matrix evaluation,
Positive Predictive Value (PPV) analysis,
Visual comparison of performance metrics across groups

## Technologies Used
Python,
Jupyter Notebook,
Pandas,
NumPy,
Matplotlib

## Project Overview
This project analyses the COMPAS recidivism dataset to examine the performance of a criminal risk assessment tool. 
The analysis explores demographic characteristics, compares prediction outcomes across different groups, and evaluates predictive performance using confusion matrices and Positive Predictive Value (PPV). 
The results provide insight into questions of fairness and consistency in risk prediction.
